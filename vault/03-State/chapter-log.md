# **HOW TO USE THIS LOG**

## **The Three-Layer Memory System**

Your project runs on three layers of memory working together:

**Layer 1 — The Bibles  ***(permanent world memory)*

Uploaded to your Claude project. Cover all world facts, characters, power system, lore, and history. Claude reads these at the start of every session automatically.

**Layer 2 — The Chapter Log  ***(recent story memory — this document)*

Claude reads and writes this document directly from the project. No pasting required.

**Layer 3 — The Chapter Character Sheet  ***(per-chapter working memory)*

Generated fresh during every /plan phase. Covers exactly who is in the current chapter, their state, and their role. Expires after each chapter.

## **The Session Start Formula**

When opening a new Claude session, just type:

/brief Chapter [X], Arc [X], Saga [X]. [Your brief here.]

— or say "continue" and Claude will read this log, confirm the last written chapter, and recap it before asking for the next brief.

## **When to Fill an Entry**

- Immediately after a chapter is approved and finalised — not before.

- Keep each entry honest and specific. 'Things happened' is useless. 'Daran left without speaking and Aldric noticed' is what Claude needs.

- If a chapter introduces new canon — a new character name, a new location, a new established fact — note it here AND run /update-bible to add it to the relevant bible.

- Arc Summary entries are filled when an arc concludes — not chapter by chapter.

## **What Each Field Means**

**What happened: **2–3 sentences. The plot events of the chapter. What changed by the end.

**Character states changed: **Who is different now and how. Emotional states, relationship shifts, new knowledge.

**New canon introduced: **Any new named character, location, spell, or established world fact that appeared for the first time.

**Closing beat / hook: **The last image or moment of the chapter. What it leaves the reader with.
